# GEOP SC / PDU Android

App Android WebView para o sistema GEOP SC / PDU.

- Nome instalado: `GEOP SC / PDU`
- Pacote: `br.com.shoppingcarpina.geopscpdu`
- URL aberta: `https://geop.shoppingcarpina.com.br/`

Para gerar o APK neste computador:

```powershell
powershell -ExecutionPolicy Bypass -File .\android\build-apk.ps1
```

O APK sai em `android/dist/GEOP-SC-PDU-debug.apk`.
